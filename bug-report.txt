[BUG-01] Prisma Client Bukan Singleton
  File: src/actions/auth.ts, dashboard.ts, hafalan.ts, kehadiran.ts, santri.ts, tes.ts, lib/auth.ts
  Setiap file bikin `const prisma = new PrismaClient()` sendiri.
  Harusnya pakai satu instance global (singleton pattern).
  Dampak: Di dev mode (hot reload), setiap save file bikin koneksi baru
  → connection pool exhaustion → crash atau hang.
  Fix: Buat src/lib/prisma.ts dengan:
    const globalForPrisma = globalThis as unknown as { prisma: PrismaClient };
    export const prisma = globalForPrisma.prisma || new PrismaClient();
    if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;

[BUG-02] Schema Prisma vs Database Mismatch
  File: prisma/schema.prisma (line 6)
  Schema tulis `provider = "mongodb"` tapi ada file `prisma/dev.db` (SQLite).
  Dampak: Build/deploy bisa gagal atau connect ke DB salah.

[BUG-03] TypeScript Types vs Prisma Schema Tidak Cocok
  File: src/types/index.ts vs prisma/schema.prisma
  Interface `Santri` punya: halaqah, noHp, alamat, avatar, targetJuz, progressJuz, joinedAt
  Prisma model cuma punya: nama, nis, kelas, status, target, createdAt, updatedAt
  Dampak: Data yang dikirim ke client component missing fields → tampil "-" atau undefined.
  Code di actions/santri.ts pakai workaround (mock noHp: "-", map kelas→halaqah)
  tapi fragile dan mudah pecah.
