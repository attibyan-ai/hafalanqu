
# HafalanQu UI Slicing

Modern UI/UX 2026 untuk sistem setoran hafalan Qur'an.

## Stack
- Next.js App Router
- Tailwind CSS
- shadcn/ui style
- Responsive design

## Pages
- Homepage
- Dashboard
- Input Hafalan
- Riwayat Hafalan
- Daftar Hadir
- Tes Hafalan
- Manajemen Santri
- Profil
- Pengaturan

## Run
```bash
npm install
npm run dev
```
